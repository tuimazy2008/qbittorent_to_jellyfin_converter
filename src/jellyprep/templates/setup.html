Подключение к qBittorrent

jellyprep берёт из qBittorrent список скачанных торрентов, раскладывает их в библиотеку Jellyfin, а потом удаляет оригиналы, когда раздача выполнена. Для этого нужен доступ к веб-интерфейсу qBittorrent (Настройки → Веб-интерфейс).

Логин и пароль можно не заполнять, если в qBittorrent включено «Пропускать аутентификацию для клиентов из списка подсетей» и адрес jellyprep входит в этот список.

TMDB — база фильмов и сериалов

Чтобы Jellyfin правильно подобрал постеры и описания, jellyprep сверяет названия с базой TMDB и пишет в имя папки её номер, например Love Actually (2003) [tmdbid-508]. Без ключа сервис тоже работает, но всё будет попадать на ручную проверку.

Как получить ключ (бесплатно, 2 минуты)
  1. Зарегистрируйтесь на themoviedb.org.
  2. Откройте Настройки → API и создайте ключ (тип «Developer», цель — личное использование).
  3. Скопируйте API Read Access Token (длинный) или API Key (короткий) — подходит любой.

Видео

Многие раздачи сделаны «с запасом»: 4K, огромный битрейт, HDR, редкие кодеки. Телевизор или телефон такое часто не тянет, и Jellyfin перекодирует фильм на лету при каждом просмотре — медленно и с подтормаживаниями. jellyprep может один раз заранее сделать копию в формате, который играет везде: H.264, не больше 1080p. Заодно освобождается место: такая копия обычно в 2–5 раз меньше оригинала.

Чем кодировать

Видеокарта (Intel Quick Sync, AMD) кодирует в десятки раз быстрее процессора и почти не нагружает сервер. Для этого в контейнер нужно передать устройство /dev/dri (см. README).

{{ card("hw_accel", "auto", s.hw_accel, "Автоматически", "Видеокарта, если она доступна, иначе процессор.", rec=True) }} {{ card("hw_accel", "vaapi", s.hw_accel, "Только видеокарта", "Intel/AMD через VAAPI. Если она недоступна — задача завершится ошибкой.") }} {{ card("hw_accel", "software", s.hw_accel, "Только процессор", "Работает везде, но медленно: фильм 4K может кодироваться много часов.") }}

HDR (яркий расширенный цвет) при перекодировании переводится в обычный цвет (tone mapping), иначе картинка получится блёклой и серой. Это делается на процессоре, потому что у многих видеокарт этот режим даёт слишком тёмную картинку, поэтому фильмы в HDR кодируются медленнее — примерно в 2 раза медленнее реального времени на двухъядерном процессоре.

В раздачах часто по 5–8 звуковых дорожек и десяток субтитров. Ненужные можно убрать — меньше путаницы в плеере. Коды языков — трёхбуквенные (ISO 639-2): rus, eng, ukr, ger, fre, spa, jpn… Если в файле нет ни одной дорожки нужного языка, остаются все.

Когда удалять оригинал из qBittorrent

После того как файл разложен в библиотеку, оригинал можно удалить, чтобы освободить место. Но честно раздать скачанное — хорошая практика, поэтому удаление ждёт, пока выполнится условие раздачи. Удаление происходит только после того, как jellyprep проверил, что файлы в библиотеке на месте.

Рейтинг — сколько раз вы раздали объём торрента: 2.0 значит «отдал вдвое больше, чем скачал». Если раздачу никто не качает, рейтинг может не набраться никогда, поэтому есть второе условие — срок. Удаление наступает при выполнении любого из условий.

Важно: если файл попал в библиотеку хардлинком (без изменений), удаление торрента место не освободит — файл остаётся в библиотеке. Место освобождается, когда файл был перекодирован или перепакован.

{{ card("preset", "r2d30", preset.name, "Раздать 2× или 30 дней", "Удалить, когда рейтинг дойдёт до 2.0 или пройдёт 30 дней раздачи.", rec=True) }} {{ card("preset", "r1d14", preset.name, "Раздать 1× или 14 дней", "Быстрее освобождает место.") }} {{ card("preset", "never", preset.name, "Никогда не удалять", "Оригиналы остаются в qBittorrent, удаляете сами.") }} {{ card("preset", "custom", preset.name, "Своё условие", "Укажите рейтинг и/или срок ниже (пустое поле — условие не используется).") }}

Это значение для всех категорий. Отдельно для каждой категории его можно поменять потом на странице «Категории».
